# 简历项目描述

## 数据分析 / BI

- 设计多数据源经营分析与指标治理平台，通过 YAML 字段语义映射和统一指标 API 实际接入 4,295,584 条 Google 官方 GA4 样例事件与 55,183 条 HMDA 真实信贷申请，动态生成 KPI、维度下钻、漏斗和质量看板，并在字段不足时自动关闭不适用模块。

## 数据开发 / 数仓

- 抽象 CSV/Parquet/SQLite/PostgreSQL 统一适配器，构建配置驱动语义层与安全 SQL 生成器，支持 count/distinct/sum/average/ratio/派生、累计及环比；用 19 个后端测试验证多数据集指标、数据质量、契约导入和能力判定。

## 央国企数据与数字化

- 将分散分析沉淀为“数据接入—口径映射—指标治理—质量校验—血缘展示—看板交付”标准流程，实现数据集版本、负责人和能力边界可追溯。
